# 🛒 E-commerce Product Page

A fully functional e-commerce product page built using **Vanilla JavaScript**, focusing on core frontend engineering concepts.

## 🚀 Features
- Dynamic product rendering
- Search and category/price filters
- Add to cart with quantity management
- Persistent cart using localStorage
- Checkout form with validation
- Responsive design
- Smooth animations and transitions

## 🧠 Concepts Used
- ES Modules
- DOM Manipulation
- Event Delegation
- State Management (without frameworks)
- localStorage
- Form Validation
- Responsive Design

## 🛠 Tech Stack
- HTML5
- CSS3 (Flexbox & Grid)
- Vanilla JavaScript

## 📦 Project Structure
- js/
    - data.js
    - products.js
    - filters.js
    - cart.js
    - cart-ui.js
    - checkout.js
    - utils.js
- css/
    - base.css
    - layout.css
    - components.css
